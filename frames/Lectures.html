  • A Data Scientist’s Toolkit: Concepts and Applications in R

    Course developed for NIA’s Biomedical Data Science Initiative (2022). Slides, recordings and class materials available here.

    The main focus of this course is to explore a variety of approaches for data analysis, with emphasis on conceptual aspects (how to select the appropriate approach for a given data analysis task, which trade-offs to consider, how to interpret the statistical output provided by different approaches) and case study implementations in R.

    Class 1: Introduction and general concepts.

    Class 2: Linear models.

    Class 3: Generalized linear models.

    Class 4: Non-linear models.

  • Review of Pathway Analysis Approaches

    Course developed for NIA’s Biomedical Data Science Initiative (2023). Slides, recordings and class materials available here.

    By casting gene-level measurements in a broader biological context, pathway analysis allows researchers to interpret their data in terms of a great variety of gene sets that may represent different functions, processes, components, or associations with disease. Over the past two decades, more than a hundred different pathway analysis methods have been developed and, concurrently, gene set repositories have grown to contain more than 30,000 human reference pathways. In this context, this course provides a general overview of pathway analysis approaches and explores in greater detail some of the most popular ones, with particular emphasis on Gene Set Enrichment Analysis (GSEA).

    Class 1: Introduction and general concepts.

    Class 2: Exploring GSEA and other popular approaches.
